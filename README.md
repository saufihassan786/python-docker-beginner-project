# Python Docker Beginner Project

## Project Overview
This is my beginner-level DevOps project. I created a simple Python application and containerized it using Docker.

## Technologies Used
- Ubuntu 24.04
- Python 3.9
- Docker
- Dockerfile
- Oracle VirtualBox

## Steps Performed
1. Created a Python application.
2. Created a Dockerfile.
3. Built a Docker image.
4. Verified Docker images.
5. Created and ran a Docker container.
6. Verified the application output.

## Docker Commands

```bash
docker build -t my-python-app .
docker images
docker run my-python-app
```
